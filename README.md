# Manual de instalación
1. Clonar el repositorio de GitHub
2. Dentro de la carpeta “utiles”, crear un nuevo archivo “variables.php”. Aquí
debes crear 4 variables, $host para la dirección IP de la base de datos MySQL,
$user para el usuario de la base de datos, $password para la contraseña del
mismo y $bbdd con el nombre de la base de datos MySQL.
3. Crear una carpeta “img” (aquí se guardaran las imágenes que suban los
usuarios)
